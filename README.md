# univrs Fleet for Android

Opens https://fleet.univrs.cloud in a full-screen WebView and adds biometric sign-in (fingerprint or face) through the phone's secure key storage.

1. Open this folder in Android Studio.
2. Build > Generate Signed App Bundle or APK > APK, pick fleet.jks, alias fleet, build type release.
3. Install the APK on the phone. It replaces the previous version in place.
4. Sign in with your password and code once, then turn on Biometric sign-in in Profile.

Passkeys and push notifications are not available inside the app.
